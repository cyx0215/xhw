# 素材库 · 可调研

这里不只是随手记灵感，而是**创作前的调研台**：

- 搜爆火题材 / 标签 / 情绪点
- 拆「为什么火」
- 变成我们能写的人物、情节、场景
- 过一遍尺度与差异化，再开新书

**不进网页**（`build.py` 不读这里）。

---

## 和我（AI）怎么协作

你可以直接说，例如：

| 你说 | 我会做 |
| --- | --- |
| 「帮我调研最近爆火的重逢/职场题材」 | 搜平台风向 → 写 `调研/日期-主题.md` → 拆 3～5 张题材卡 |
| 「校园成人向有什么还能写的角度」 | 列热梗 + 同质化雷区 + 我们可微创新的切口 |
| 「把某某题材做成可写大纲」 | 从题材卡扩成章纲，必要时新建 `books/` |
| 「检查这批素材能不能用」 | 对照 `索引.md` 改状态，标风险与适配书 |

调研产出默认进：

1. `调研/` — 简报（来源、结论、优先级）
2. `题材/` — 一张卡一个可写方向（含热度、公式、我们的改法）
3. 需要时再拆到 `人物/` `情节/` `场景/` …

## 目录

```text
素材/
├── README.md
├── 索引.md                 # 总览与开写前检查
├── _模板/
│   ├── 素材卡片.md         # 单点灵感（人物/场景/对白…）
│   ├── 爆款题材卡.md       # 可调研的题材单位（推荐）
│   └── 调研简报.md         # 一次搜索的结论归档
├── 调研/                   # 按日期的调研报告
├── 题材/                   # 爆火/可写题材库（核心）
├── 人物/ 情节/ 场景/ 对白/
├── 感官/ 结构/ 金句/ 摘录/
```

## 工作流（推荐）

```text
搜风向 → 写调研简报 → 落题材卡 → 你检查（索引改状态）
       → 可用卡拆成人物/情节/场景 → 开 books/新书
```

1. **调研**：一次一个主题（如「破镜重圆+职场」），产出简报  
2. **沉淀**：每个值得写的方向 → 一张 `题材/爆款题材卡`  
3. **检查**：你在 `索引.md` 标 `待看 / 可用 / 暂缓 / 已用 / 弃用`  
4. **开写**：可用题材迁入 `books/<书名>/设定/`，细节进 `笔记/`

## 调研时我们看什么

| 维度 | 问题 |
| --- | --- |
| 热度 | 平台标签、短剧互文、搜索词是否仍在涨 |
| 情绪 | 读者买的是遗憾弥补、禁忌、反差、掌控感还是释放 |
| 公式 | 开篇钩子 → 中段拉扯 → 高潮场景 → 收束 |
| 同质化 | 烂大街写法是什么，我们怎么偏 15° |
| 适配 | 是否贴合我们已有调性（都市情欲、重逢、克制后爆发） |
| 边界 | 平台合规、伦理雷区、是否写未成年（**一律不做**） |

> 原则：学**结构与情绪机制**，不抄书名、情节链、人设组合与原句。

## 和 books/ 的关系

| 位置 | 干什么 |
| --- | --- |
| `素材/调研` | 市场与风向，会过期，可再搜 |
| `素材/题材` | 跨书可复用的「故事种子」 |
| `books/<书>/设定` | 这本书定死的设定 |
| `books/<书>/笔记` | 这本书的灵感与待改 |

题材卡标「已用」后写上书名，避免重复开同一坑。
