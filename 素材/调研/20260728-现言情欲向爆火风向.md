## 1. 一句话结论

**常青情绪仍是「遗憾弥补 + 权力差 + 反差」**；大众站要合规包装，私密/成人向可走我们现有路线。  
最值得我们立刻写的不是新奇世界观，而是：**旧梗换关系位与场景**，短篇 1～3 万字、开篇即钩子、名场面密度高。

## 3. 高频公式（可复用结构）

1. **开篇**：身份错位重逢 / 被迫共处（同一项目、同一酒店、同一考场）  
2. **中段**：身体或气氛先破冰，旧账与自尊拉扯，信息差（谁先动心）  
3. **高潮场景**：一个封闭空间名场面（雨夜、出差房、空教室、车后座）  
4. **收束**：谈妥规则或谈妥心；短篇可「身体契约 → 情感破功」

## 4. 同质化与雷区

- 已经写烂的：空霸总、无细节办公室、纯肉体无人物、强行 NTR 猎奇堆料  
- 平台/伦理雷：**任何未成年性描写（禁止）**；非自愿、迷奸等需极谨慎或避开  
- 我们应避开：复读/校园若写，角色必须**明确已成年**（与《高中生的秘密》一致）  
- 抄袭雷：不搬热书情节链与人设三件套
