# 小说写作工作区

本目录用于以 Markdown 手写 / 协作写作小说。

## 目录说明

```text
xhw/
├── README.md                 # 本说明
├── build.py                  # 阅读页生成器（零依赖）
├── site/                     # 生成的网页，可整个打包发出
│   ├── index.html            # 书架首页
│   └── <书名>.html           # 每本书一个独立页面
├── templates/                # 可复用模板（新建作品时复制）
│   └── book.toml             # 书籍元信息模板
├── 素材/                     # 跨作品原料库（不进网页）
│   ├── 索引.md               # 待看 / 可用 / 已用
│   ├── _模板/素材卡片.md
│   └── 人物·情节·场景·对白…  # 分类卡片
├── books/                    # 各部作品
│   └── 示例作品/             # 可改名或复制后使用
│       ├── book.toml         # 书名、题引、主色、连载状态
│       ├── 设定/
│       │   ├── 世界观.md
│       │   ├── 人物.md
│       │   ├── 大纲.md
│       │   └── 时间线.md
│       ├── 章节/
│       │   └── ch001.md
│       └── 笔记/
│           ├── 灵感.md
│           ├── 伏笔.md
│           └── 待改.md
```

### 素材库（可调研 · 写新文章前）

`素材/` 是创作调研台：可搜爆火题材、归档简报、落题材卡，再开新书。

```text
搜风向 → 素材/调研/简报 → 素材/题材/卡片 → 你检查索引
       → 开 books/新书
```

直接对我说例如：

- 「帮我调研最近爆火的重逢/职场题材」
- 「校园成人向还有什么能写的角度」
- 「把某某题材扩成大纲并新建书」

详见 `素材/README.md` 与 `素材/索引.md`。素材目录**不会**被 `build.py` 编译进网页。

## 导出成可分享的网页

纯标准库，无需安装任何依赖：

```bash
python build.py              # 构建一次 → site/
python build.py --watch      # 写小说时开着：改完自动重建
python build.py --serve      # 推荐：本地预览 + 自动重建 + 浏览器热刷新
python build.py --serve 9000 # 指定端口（默认 8765）
```

### 日常写作（推荐）

开一个终端跑：

```bash
python build.py --serve
```

浏览器会打开 `http://127.0.0.1:8765/`。之后你只要改 `books/` 里的章节或 `book.toml` 并保存，网页会自动重建，浏览器大约 1 秒内自动刷新。`Ctrl+C` 结束。

只想自动重建、自己双击 `site/` 里的 HTML 看，用 `--watch` 即可。

### 产物

产物在 `site/`：

- `index.html` — 书架首页，卡片列出所有作品，点开进入阅读
- `<书名>.html` — 每本书一个独立单文件页面，双击即开，不依赖服务器或网络，**可单独发微信 / 邮件**

目录、章数、字数全部自动更新。新增章节或新增整本书都不用改脚本。

热刷新脚本只在 `--serve` 时注入到浏览器响应里，**不会写进** `site/*.html`，分享出去的文件依然是干净的单页。

阅读页功能：侧栏目录（宽屏常驻 / 手机抽屉）、滚动高亮当前章、阅读进度条、字号四档、日间 / 夜间（跨页保持，首次访问跟随系统）、记住上次读到的位置、左右方向键翻章、打印时每章另起一页。

### 每本书的元信息：book.toml

放在 `books/<书名>/book.toml`，所有字段都可省略：

| 字段 | 说明 |
| --- | --- |
| `title` | 书名（默认取目录名） |
| `subtitle` | 副标题，如「第一卷」 |
| `tagline` | 一句话简介，显示在书架卡片上 |
| `epigraph` | 封面题引，支持 `<br>` 换行 |
| `status` | `连载中` / `已完结` |
| `adult` | `true` 时书架卡片显示「成人向」角标 |
| `accent` | 该书主色，书架卡片与阅读页共用 |
| `cover` | 封面图路径，留空则用主色生成式封面 |
| `order` | 书架排序，小的在前 |

`templates/book.toml` 是带注释的模板，复制过去改即可。

### 正文书写约定

生成器按以下约定排版，写作时保持一致就行：

| 写法 | 渲染效果 |
| --- | --- |
| `# 第 N 章 · 标题` | 章标题，同时生成目录项 |
| `# 第一章　标题` | 同上，汉字章号也认 |
| `## 正文` | **有这行时，只有它到下一个 `##` 之间的内容会进入网页** |
| 单独一行的 `一` `二` `三` | 装饰性分节符 |
| `### 一、小标题` | 带小标题的分节符 |
| 空行 | 分段 |
| `> 文字`（连续多行） | 手机消息气泡 |
| `**文字**` / `*文字*` | 加粗 / 斜体 |
| 行尾两个空格 | 段内换行（不另起段） |
| `（第 N 章 · 终）` | 章末标记，居中淡化 |

**创作笔记不会外泄**：`## 本章目标`、`## 章后笔记`、标题下方的 `> 状态 / 字数目标 / 视角人物` 等，只要正文放在 `## 正文` 下，就都不会出现在网页里。`设定/` 与 `笔记/` 整个目录也不会进入产物。

想让某本书不出现在书架上，把目录名加进 `build.py` 顶部的 `EXCLUDE`（`示例作品` 已默认排除）。

## 新建一部作品

1. 复制 `books/示例作品`，改名为你的书名  
2. 或从 `templates/` 复制对应模板，填入 `books/你的书名/`  
3. 复制 `templates/book.toml` 到书目录下，填书名、简介、主色  
4. 先写 `设定/`，再按 `章节/ch00N.md` 推进正文  
5. 灵感、伏笔、待改清单放在 `笔记/`  
6. 跑 `python build.py`，新书会自动出现在书架上

## 命名建议

- 章节：`ch001.md`、`ch002.md` …（三位数字，方便排序）
- 人物可按需拆分：`人物-主角.md`、`人物-配角.md`
- 长篇可按卷拆：`章节/卷一/`、`章节/卷二/`

## 写作节奏建议

1. 世界观与人物定骨架  
2. 大纲写到卷/章级即可，不必一次写死  
3. 每章写完后，在 `笔记/伏笔.md` 更新状态  
4. 修改意图记在 `笔记/待改.md`，避免边写边忘
