# 尺度与边界 · 《高中生的秘密》

## 总原则

**先克制，后爆发。**  
读者欲望靠：禁止、等待、差点发生、事后回味。  
**不靠**连续多场做爱堆字数。

全书定位：**激情，但不低俗**。成人向甜涩成长文；全员 **≥18**；身份为复读/社会考生备考，避免未成年校园符号。

### 文风红线（群像与旁人）

| 允许 | 禁止 |
|------|------|
| 闺蜜夜里被窝/合租房里的**悄悄话** | 食堂、教室、群聊里起哄「谈了吧」「不行吧」 |
| 男生室友关灯后的**低声试探** | 公开损黄、性暗示玩笑当笑点 |
| 旁人旁敲侧击、欲言又止、眼神 | 朋友圈/大群曝光式起哄 |
| 用成绩、状态、距离说话 | 油腻台词、低俗比喻堆砌 |

原则：**秘密之所以是秘密，是因为外面的世界安静、克制；只有最近的人，才在私密空间里把话说半句。**  
激情写在双主之间（感官、心理、关系），不靠群嘲烘托。

## 关于「D：第一次专章模板」（你上次说没看懂）

那不是要你交作业，只是**写第一场完整亲密戏时的结构备忘**：

| 拍 | 写什么 | 作用 |
|----|--------|------|
| 1 触发 | 为什么是今晚（模考、崩溃、确认心意） | 不突兀 |
| 2 心理 | 她的警戒、**两人各自的饿**、羞耻与自我镇压 | 人还在 |
| 3 身体 | 生涩、停顿、确认、快感 | 尺度落地 |
| 4 余波 | 第二天怎么对视、成绩、关系 | 戏有后果 |

**你现在阶段**：先写克制与靠近，**暂时不用写 D**。等大纲里「爆发章」再启用。

## 尺度阶梯（按关系进度，不按章硬塞）

| 级别 | 内容 | 本书策略 |
|------|------|----------|
| L0 | 注视、间距、声音、气味、差点碰到 | **前 30% 写满** |
| L1 | 牵手、拥抱、额头/唇角、隔衣 | 中前段，珍贵 |
| L2 | 深吻、抚触、互相解决、边缘 | 中段 1–2 场足够狠 |
| L3 | 完整做爱（生涩、确认、事后） | **爆发主菜，宜少宜重** |
| L4 | 已熟悉后的放纵、半风险场合 | 可选 1 场，服务「破冰后他极想要」 |

**默认峰值**：L3 精写 2–3 场；L2 精写 2 场；其余全是 L0–L1 的「饿」。

## 床戏功能表（质量 > 数量）

| 场次 | 建议位置 | 功能 | 情绪 |
|------|----------|------|------|
| 差点亲上 | 约 25% | 证明双方都有反应；她后退 | 惊、羞、悔 |
| 第一次深吻+拥抱失控 | 约 40% | 破「不能靠近」 | 喘、怕、甜 |
| 互相抚慰/半套 | 约 55% | 他欲望外泄；她第一次允许身体 | 生涩、震惊「原来这么想要」 |
| **第一次完整** | 约 65–70% | 爆发点；秘密升级 | 疼、爽、哭、抱紧 |
| 模考后安抚式 | 约 80% | 关系从欲望→依靠 | 慢、说话、温柔 |
| （可选）考前最后一次 | 约 90% | 「极想要」与克制并存 | 急、珍惜 |

以上共约 **4–6 场有肉体推进的戏**，其余章节用学业、对话、目光把读者吊住。

## 提高欲望的非肉体技巧（本书主力）

1. **时间**：自习到 22:40，只剩他们，灯一盏  
2. **规则**：她说「十一点后不语音」——他 22:59 发来一句「今天数学卷第 18」  
3. **排名**：她超他一名，他笑着说恭喜，手指把笔捏到发白  
4. **身体局部**：腕骨、后颈、唇干、耳尖——反复写，形成条件反射  
5. **他的独自解决**：可侧面写（不直白到恶心），强化「私下极强」  
6. **她的否认 + 她的私欲**：嘴上「没有」；夜里可写她也睡不着、也走神、也夹紧被子——点到即止，与他对位  
7. **第三者误读**：室友/损友**私下**点破半句 → 当事人沉默或轻描淡写，不演闹剧  
8. **双饿信息差**：读者早知道她也想要；许昼长时间以为只有自己在脏——他心疼/自责时读者更痒

## 必须遵守

1. **年龄**：性描写角色均为成年；可写「复读」「已满十八」钉死  
2. **合意**：她警戒高，每一次升级都要有**她的允许或主动一步**（哪怕很小）；她内心想要 ≠ 可以省略同意  
3. **人设一致**：  
   - 许昼：人前保守；确认后才凶、才贪；不会一上来技巧大师  
   - 苏晚宁：**内心一直想要**，表面冷静后退；不会突然变浪女，但爆发后可以很诚实、很贪；破冰前用「不想」撒谎，破冰后用行动承认  
4. **安全**：第一次完整建议有套/沟通；可写紧张忘记，但事后态度要有  
5. **不写**：未成年、迷奸当糖、公开强制羞辱、NTR 主线、纯工具人轮换床伴

## 语言

- 器官可直写，但夹内心与关系潜台词  
- 禁止连续纯动作段超过半页还不回人物  
- 许昼破冰后的脏词：可以有，但要像「忍不住漏出来」，不是全程黄腔  

## 身体写法（ch08 / ch10 / ch13 统一）

- **女主少说「想要」**：用点头、嗯、可以、慢、轻、抓床单、埋脸、身体迎送  
- **多写身体**：触感、水声、温度、呼吸、乳尖、交合处、抽插节奏、高潮收缩、余韵清理  
- **私处同一细度**（女主/闺蜜/与男主场景统一）：阴毛分布与颜色、外阴厚薄、缝与核的形状颜色、入口开合、湿意与高潮后合不拢——服务幻想，忌流水账重复  
- **过程说清楚**：进了多少、疼在哪、磨哪里、换角度、射精时隔套的跳动、退出后的合不拢与空虚  
- **纯天然**：阴毛/腋毛未处理，边缘不齐，湿后贴肤——真实，不猎奇羞辱  
- **第一次握**：单独写清生涩、力道、形状、她的停顿与确认  
- 过程阶段：隔衣 → 裸触 → 口/指 → 握 → 进入 → 节奏变化 → 高潮 → 清理  

## 机构内擦边 / 破例（ch11 起）

- **常规**：资料室等可锁处——口、互相手；细节写清，更写**前后反差**  
- **考前破例（ch15）**：**空教室全套**一次——并桌、黑板红字、光荣榜名字对照；有套；听声即停；事后清痕迹  
- **反差公式**：讲台 / 「互相监督」/ 老师夸奖 / 保安夸用功 → 课桌上进入  
- **出来立刻切换**：撞见保安仍能平稳「对最后一套卷」  
- 原则：刺激来自「仍是好学生」；全套仅限人散、可听声、可善后，不写当众暴露玩法  

## 闺蜜讨论（允许，且要写）

- **场景**：合租关灯、锁门、压低声音——绝不公开起哄  
- **内容可具体**：到哪一步、疼不疼、套、握的手感、顶到哪一点、毛、水声、事后坠胀  
- **唐果功能**：拆解羞耻、给安全建议（套/停/清理）、把「爽」从「脏」里救出来  
- **唐果真相**：其实也是**处女**；知识来自书/网；聊多了五味陈杂，会偷偷自慰  
- **撞见戏**（ch11）：晚宁早回撞见 → 不嘲笑、互认秘密；唐果承认装懂与空虚  
- **闺蜜互扣**（ch11）：低度酒；半玩笑半同意；晚宁先指挥唐果；再两指→三指深入唐果（疼+高潮）；互不替代主 CP；可告知许昼 
- **晚宁功能**：说细节时短句、耳尖红、埋脸——仍是她，不是突然变浪  
- 原则：**私下谈细节 = 真实与陪伴**；当众起哄 = 禁止
