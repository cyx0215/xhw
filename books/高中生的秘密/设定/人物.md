## 主要人物总表（10 人）

全书以 **双主线 + 八功能位** 撑住：秘密、成绩、家庭、误会、暴露风险，不写成群像摊大饼。

|---|------|------|------------|------|
| 1 | **许昼** | 男主，19，复读 | 阳光保守壳 / 私下极饿 / 破冰后极想要 | 主 |

## 主角

### 1. 许昼（男主）

| 项目 | 内容 |
|------|------|
| 姓名 | 许昼 |
| 年龄 | **19**（复读年已满十八，正文可点明） |
| 身份 | 复读机构「启明」理科班；上一年差 8 分未进理想院校 |
| 外貌关键词 | 个子高、肩宽、笑起来见牙、皮肤晒得健康、手指骨节分明 |
| 性格关键词 | 阳光、外向、嘴甜、**公开场合极保守**、私下欲望极强、破冰后黏且凶 |
| 性经验 | 零；最多是深夜自己解决，事后有轻微罪恶感 |
| 成绩 | 稳年级前 30；物理强、英语靠刷；能聊也能学 |

#### 背景

- 家境普通小康，父母温和但「再读一年必须出分」
- 高中时人缘好，被当成「开朗好同学」，没人把他和欲望联系在一起
- 复读后住机构附近合租单间，生活规律到像军人
- 对恋爱的公开态度：高考前不考虑；私下：会因为一个后颈、一截腕骨硬一整晚

#### 「阳光保守」怎么写

- 帮同学搬水、组织小组、笑话讲得恰到好处
- 有人旁敲侧击，他笑着把话题拨回题目；不接油腻玩笑
- 座位间距、递笔角度、目光停留，都有自我审查
- **越克制，读者越知道他在忍**

#### 「破冰后极想要」怎么写

- 不是瞬间变流氓，是：**确认她也要之后，压抑的闸门开了**
- 特征：呼吸重、话变少、眼神发直、事后会抱很久、第二天又装没事（前期）
- 中后期：敢说「我想要你」，且说完还会脸红——阳光壳还在

#### 动机与目标

- 表层：今年必须考上 A 大
- 深层：想被一个人认真地、单独地需要；不是大家的「好许昼」
- 恐惧：欲望耽误成绩；被她当成轻浮的人；破冰后收不回来

#### 人物弧线

- 起点：用开朗掩盖饿；把所有冲动折进跑步和冷水
- 转折：第一次被她允许靠近 → 发现自己比想象中更贪
- 终点：能把「想考上」和「想要你」放在同一句话里，不再二选一式自欺

#### 欲望钩子（给读者）

- 他越是「好同学」，读者越想看他失控
- 写他的手：握笔、捏拳、放在自己膝上不敢伸
- 写他的笑：对别人是阳光，对她会突然卡半秒

### 2. 苏晚宁（女主）

| 项目 | 内容 |
|------|------|
| 姓名 | 苏晚宁 |
| 年龄 | **18 刚满**（复读年生日已过，正文钉死成年） |
| 身份 | 同机构文科/综合班转理科补弱项；上一年因心理压力发挥失常 |
| 外貌关键词 | 清淡、锁骨明显、耳尖易红、不化妆也干净、卫衣帽子常戴着 |
| 性格关键词 | **I 人**、对熟人话多到停不住、对外人极简、警觉高、慢热、一旦认定就很轴 |
| 性/恋爱态度 | **内心其实很想要** + **表面高警戒、低主动**：不是冷感，是把饿死死按住 |
| 成绩 | 语文英语顶尖，数学曾是短板，复读后咬着补；综合排名常压许昼一头（刺激点） |

#### 背景（想象力发挥）

- 单亲，跟母亲；母亲温柔但反复说：「女孩子先把自己顾好，别那么早陷进去。」
- 高中有过一次「差点恋爱」：对方表白，她拒绝后对方在班级群阴阳——从此把亲密关系当成高风险区
- 复读原因：考场上突然空白半小时，分差不致命，但她无法接受「失控的自己」
- 住机构女生合租，室友外向；她只在夜里给一个远方发小语音，能连说四十分钟
- **私欲**：并非不懂情欲。会做带颜色的梦、会在洗澡时走神、会因许昼的手腕/声音/靠近而腿软——然后立刻用「恶心」「分心」「不许」骂自己

#### 「I 人但对熟人话多」

- 对班里：点头、嗯、借橡皮道谢就结束
- 对许昼（熟了之后）：会突然讲错题思路、吐槽食堂、分析老师出题习惯，话密得他自己插不进
- **反差萌 + 亲密感**：读者感到「只有他听得到这个版本的她」

#### 「内心想要 × 表面警戒」怎么写（核心）

**一句话人设：她不是不想，是太想了，所以更怕。**

| 层 | 表现 |
|----|------|
| 嘴上 | 「没有」「随便」「我们是搭子」「别这样」 |
| 身体 | 耳尖红、呼吸乱、睡不着、反复回放触碰、夹紧笔的手指 |
| 行为 | 立规矩、后退、把话题拽回学习；**却又主动要错题本、破十一点、还坐原位** |
| 夜里 | 独自承认「我想要」三个字，天亮假装失忆 |

**警戒清单**（她用来骗自己的缰绳）：

1. 不能单独去对方房间  
2. 不能超过晚上十一点微信语音  
3. 不能让成绩曲线因人波动  
4. 不能先说「喜欢」  
5. **不能先承认自己也想要**（最硬的一条）

**与许昼的对位**：

- 他：公开不饿，私下极饿 → 破冰后外泄  
- 她：公开不饿，**私下同样饿** → 破冰前更会演「冷静」  
- 双饿对撞：克制才好看；爆发时她也可能先抓住袖口，而不是纯被推倒  

**写法禁忌**：

- 不要写成木头冷感突然变浪  
- 不要写成「其实一直发骚」的油腻内心独白  
- 要写：**欲望真实 + 羞耻真实 + 自我镇压真实**；想要本身也让她害怕  

**燃点优先级**：

1. 她忍住没亲回去的那几秒（比亲上更欲）  
2. 规矩被**她自己**打破（身体先于嘴承认）  
3. 某次她先主动一点点（拉袖口、回吻、说「可以」）  
4. 爆发后她发现：自己比想象中更贪——与他对称  

#### 动机与目标

- 表层：证明自己不是「会崩的那种人」；稳进目标院校  
- 深层：想要他，想要被好好要；又想要这份想要「合法」、不被骂轻浮  
- 恐惧：重演被议论；欲望真的耽误分；许昼发现她也这么想之后会轻视她；**自己承认渴望后收不回来**

#### 人物弧线

- 起点：把饿和人一起挡在安全距离外，用成绩当盾  
- 转折：发现许昼也在忍 → 她的「只有我在胡思乱想」崩塌 → 更危险也更安心  
- 终点：敢在清醒时说「我也想要」；考场与床都不再是互相否定的两极  

#### 欲望钩子（给读者·提高欲望但不靠堆肉）

1. **双饿**：读者知道两人都想要，只差谁先破  
2. **禁止感**：她设的规矩 = 读者想看破的关卡  
3. **话多只给他**：语言亲密先于身体亲密  
4. **身体诚实、嘴不诚实**：「没有」vs 耳尖红、腿心发热（点到即可）  
5. **自习走神**：题做着做着想起他呼吸——再用力划掉草稿  
6. **慢热但每一次第一次都有重量**：牵手、回吻、进房、过夜  
7. **她先主动的瞬间**：全书欲望峰值之一，比他扑上来更炸

## 二人关系公式

```
公开：同机构复读生 / 偶尔一组讨论 / 好同学
半公开：固定邻座自习、共享错题本、饭点「顺路」
秘密：互相知道对方在忍；触碰；未说出口的喜欢；日后的身体关系
张力源：他的饿 × 她的饿 × 她的警 × 共同的分
爆发条件：不是酒，是「确认对方也想要」+ 高压节点（模考后/出分前夜）
```

### 为什么配

| 他 | 她 | 化学反应 |
|----|----|----------|
| 外向壳 | 内向核 | 他负责递台阶，她负责要不要踩 |
| 私下极饿、公开守规矩 | **内心同样想要、表面更会演冷静** | 双忍；谁先裂开谁输（也是谁先赢） |
| 破冰后极想要 | 破冰后才敢承认自己也贪 | 对称爆发，不是「他教她」单箭头 |
| 怕被当轻浮 | 怕被当轻浮 | 共同羞耻感；互相确认后才敢放 |

### 称呼演变

- 前期：许昼 / 苏晚宁（全名）
- 中期：许昼同学 → 许昼；她被叫「晚宁」会僵一下
- 破冰后私下：昼；宁宁（他先用，她会抗议但允许）

## 主要配角（详设）

### 3. 赵屿（许昼室友）

| 项目 | 内容 |
|------|------|
| 年龄 | 19 |
| 身份 | 启明复读；与许昼合租两居室 |
| 外貌关键词 | 瘦、黑框眼镜、拖鞋声很响 |
| 性格关键词 | 嘴碎、八卦但讲义气、夜猫子、成绩中上 |

#### 功能

- **暴露风险**：听见浴室水声过长、看见回消息时的停顿、撞见深夜「送人」
- **对照**：自己也有说不出口的事，所以后来更懂闭嘴
- **态度演变**：起疑 → 关灯后低声问一句 → 点到为止 → 知情后默契帮衬，不宣扬

#### 关键句式（宜私密、半句）

- 「你最近……状态有点不对。不是说分。」
- 「需要我装睡的时候，说一声。」

#### 弧线（轻）

从观察者到守口如瓶的室友——男主侧少数知情者。

### 4. 唐果（苏晚宁室友）

| 项目 | 内容 |
|------|------|
| 年龄 | 18+ |
| 身份 | 启明复读；与晚宁合租 |
| 外貌关键词 | 马尾、运动外套、声音亮 |
| 性格关键词 | 热心、直球、护短、嘴上老练、**其实也是处女** |
| 性经验 | **零**；安全知识来自书/网上，聊多了会心虚 |
| 内心 | 听晚宁讲细节后五味陈杂：护她、羡慕、燥、空虚、怕自己下流 |

#### 功能

- **推进器**：拉晚宁吃饭；**只在合租夜里**谈感情与身体细节
- **对照**：嘴上能把步骤拆得像错题，身体却从未经历——与晚宁「做过」形成另一种反差
- **暗线**：聊多了偷偷自慰 → 被晚宁撞见 → **小酒后半玩笑半认真互相扣**（晚宁更懂、先指挥、后把唐果三指打开至高潮）→ 仍是闺蜜，不替代主 CP

#### 关键句式（宜闺蜜悄悄话）

- 「我不是要管你。就是……你看他的时候，不太像看同桌。」
- 「累了就靠一下。我听着，不往外说。」
- （被撞见后）「别用那种眼神。我……也就是听多了。」

#### 弧线（轻）

从「装懂的护短闺蜜」→ 承认自己也燥、也是第一次听这些 → 与晚宁并排做会脸红的人，而不是高高在上的人生导师。

### 5. 何予川（竞争者 / 轻量情敌）

| 项目 | 内容 |
|------|------|
| 年龄 | 19 |
| 身份 | 启明理科常年前三；上一年差理想校一线 |
| 外貌关键词 | 清俊、衣服熨帖、说话慢条斯理 |
| 性格关键词 | 礼貌、克制、好胜藏在分数里、不抢不闹 |

#### 功能

- **成绩压**：模考常压许昼，或与晚宁并列——刺激许昼「阳光」下的不甘
- **对晚宁**：欣赏她的冷静与英语，会单独约「讲一套阅读题」（正当学习）
- **张力**：晚宁因「安全」更易接受何予川的学习邀请 → 许昼酸但不肯承认
- **不是恶毒男二**：不造黄谣、不强迫；最大杀伤力是「正当且优秀」

#### 关键句式

- 「苏晚宁，这套题你有空的话，我们可以对一下。」
- 对许昼：「你同桌很强。你也是。」（礼貌刀）

#### 弧线（轻）

中后段察觉两人有事，主动退半步，一句话成全：「别把分和人弄混。」

### 6. 林夏（玩笑型触发器）

| 项目 | 内容 |
|------|------|
| 年龄 | 18+ |
| 身份 | 启明文科班，与许昼同机构、常一起搬水/小组 |
| 外貌关键词 | 利落短发或高马尾、笑点低 |
| 性格关键词 | 外向、利落、损友感克制在分寸内 |

#### 功能

- **对照线**：与许昼小组讨论、顺路买奶茶——**正常同学距离**，不加肢体玩笑
- **衬托人设**：许昼对林夏始终「好同学」；对晚宁才破功
- **澄清**：林夏另有在意的人（点到为止），不构成三角

#### 关键句式

- 「你同桌英语真好。有空让她带带我？」
- 「最近别太拼，黑眼圈都连片了。」

#### 注意

误会若有，用**晚宁自己的敏感**推动，不靠林夏当众撩拨；短收，不拖泥潭。

#### 关键句式

- 「许昼，苏晚宁，你们最近状态我看在眼里。」

### 10. 宋辞（晚宁发小 / 树洞）

| 项目 | 内容 |
|------|------|
| 年龄 | 18–19 |
| 身份 | 外地读大一或同城偶来；与晚宁初中起的发小 |
| 性格关键词 | 稳、损、懂她、不逼问细节也能听懂 |

#### 功能

- **语音树洞**：晚宁 I 人话多模式的主要出口（前期）；后半被许昼部分替代
- **知情者**：第一个知道「差点被亲」「规矩破了」的人
- **理智旁白**：提醒「你是怕，还是真的不想」
- 可线下探班一次，与许昼短兵相接（打量、警告、认可）

#### 关键句式

- 「苏晚宁，你这是警戒，不是没感觉。」
- 对许昼：「她脆。你要是玩玩，我跨省揍你。」（半玩笑半真）

#### 弧线（轻）

从「替她挡世界」到「把位置让给一个值得的人」。

## 写作时的人物检查清单

写每一章前问：

1. 许昼这章是在 **装阳光** 还是 **裂缝**？
2. 苏晚宁这章是在 **立规矩** 还是 **破自己规矩**？有没有写出 **她也想要却在按**？
3. 有没有用成绩/排名/时间表顶住欲望？（两人各自都要有）
4. 若有亲密，是推进关系，还是可删的重复爽点？
5. **本配角出场是否推动主线**（暴露 / 误会 / 压力 / 对照）？推不动就删戏。
6. 同时在场是否超过 4 人说话？超过则易散——优先双人戏。
7. 女主内心独白：是「不想」还是「想要但不许」？后者才对。
