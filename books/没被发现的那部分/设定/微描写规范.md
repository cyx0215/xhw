# 微描写规范 · A 档（+15%）

> 用于全文细腻化增强。默认浓度 A；沉沦章（3–6、14）可局部贴近 A+，仍禁止灌水。

## 总目标

- **引起性欲但不反感**：具体、真实、有温度；不油腻堆砌，不猎奇，不侮辱角色。
- **转场通顺**：每场有「靠近 → 停顿/退路 → 越过或收回」的呼吸。
- **语言真实动人**：像人会说的话、会做的小动作；少主题演讲。

## 浓度

| 项 | 标准 |
|----|------|
| 净增字数 | 约 **8%～15%**/章（沉沦章上限约 20%） |
| 每千字 | 约 **2～4 处**有效微描写（身体或半成品心理） |
| 默认句式 | **一个小动作 + 半句可读心理**，不写议论文 |

## 身体语言四级

| 级 | 用途 | 示例方向 |
|----|------|----------|
| L1 无意识 | 日常、未越线 | 袖口、对齐鞋尖、杯沿挡嘴 |
| L2 压抑 | 想碰不敢 | 手伸一半改拿别的；目光停 0.3 秒 |
| L3 裂缝 | 公开险露馅 | 筷磕碗、笑晚半拍、耳尖热（一章 1～2 次） |
| L4 沉沦/结痂 | 私密或终章 | 十指、呼吸同频；一年后手很稳 |

## 心理四种句型（优先用）

1. **自我纠正**：想说 A，出口变成 B  
2. **身体记忆串台**：当下触感叠上另一场景  
3. **道德拆账**（许淮）：欲望与内疚分栏  
4. **未说出口的半句**：后半截烂在齿间  

## 角色词典（勿串味）

| 角色 | 心虚/紧张 | 动情 | 结痂后 |
|------|-----------|------|--------|
| 许淮 | 先做事再说话；剥虾/倒茶/锁屏；玩笑挡箭 | 嗓先哑；手稳话短；诚实难看 | 动作更匀；笑时眼停半拍 |
| 晚晚 | 收拾、对齐、捏杯盖；话少但准 | 耳尖/脖侧；抓住再松；「不是不想」 | 笑温柔手稳；偶顿即平 |
| 予希 | 少心虚；摊、脚晃；信任时动作大 | 心情好才缠；日程表欲望 | **始终松弛**（对照刀） |

### 三人同场公式

予希大动作 → 晚晚小停顿 → 许淮功能动作圆场  

## 情欲段规则

- **细在**：靠近、停顿、不敢看、同意的瞬间、事后的手与空白  
- **不细在**：重复抽插形容词堆叠  
- 尺度可满，但保持慌乱/真实/体外习惯；不极端暴力、不强迫狂欢  
- 对比：予希「熟、看心情」vs 晚晚「生、紧、易慌」

## 感官配额

每场景 **1～2 种**（触/听/嗅/视），勿全开。

## 禁词与防重复（通读时清理）

单章内避免反复刷：

- 指节发白、耳尖红、喉结滚动、深吸一口气、空气凝固  
- 「他很心虚/她很矛盾」类结论形容词  

同一生理反应换部位或换动作表达。

## 改写检查清单（每章改完自检）

- [ ] 转场是否有「可退回」的一刻（哪怕没退）  
- [ ] 性描写是否具体而不脏到厌  
- [ ] 心理是否半成品，而非主题总结  
- [ ] 予希是否仍可信地「不察」  
- [ ] 字数是否仍像「略增」而非新小说  
- [ ] 与前后章称呼、事实、伏笔不冲突
