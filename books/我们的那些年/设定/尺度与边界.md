# 尺度与边界 · 《我们的那些年》

## 总原则

原文几乎 **零肉体戏**（醉酒同床也「什么都没发生」）。  
本版定位：**情感密度保留 + 情欲戏加量**，服务「守礼崩溃」与复合，不写成无剧情的纯肉文。

## 尺度阶梯（按章推进）

| 级别 | 内容 | 建议出现 |
|------|------|----------|
| L0 | 凝视、心跳、醉酒肢体、腹肌、同床未做 | ch01–03 重写保留并写满 |
| L1 | 深吻、啃咬、隔衣抚触、顶弄、互相手淫 | ch04 |
| L2 | 口交、指奸/扩张、边缘反复 | ch04 末～ch05 前 |
| L3 | 插入式性交（可多体位）、内射/套、事后清理 | ch05 起主菜 |
| L4 | 吃醋炮、半公开场所风险、道具（可选，不强制） | ch06+ 按需 |

**默认目标**：全文峰值到 **L3**，L4 点到爽即可，不压过感情线。

## 必须遵守

1. **合意**：酒后若有越界触碰，次日清醒后口头确认；第一次全垒双方清醒自愿  
2. **年龄**：所有性描写角色均为成年；童年闪回禁止性化  
3. **安全**：第一次建议写套或事后说明；可有「没忍住」但要有态度  
4. **人设一致**：  
   - 顾：破戒前克制，破戒后可以凶、可以哭、可以极缠  
   - 牧：嘴上凶、身体急，初夜允许技术一般但主导欲强  
5. **不写**：迷奸当糖、未成年、血腥性虐主线、NTR 强制绿（吃醋回忆可，不真绿主 CP）

## 重写 ch01–03 的尺度任务

- **不要**为了加肉硬塞全垒进前三章（东郊还在撕）  
- **要**写满：  
  - 牧对顾的性化注视（喉结、手、笑、腹肌）  
  - 醉酒时顾的体温、扶抱、放上床时的呼吸距离  
  - 晨间勃起/尴尬可点一下（合意氛围，非强迫）  
  - 「要真有什么哪会等到现在」之后的**后悔与硬了**

## 语言风格

- 对齐工作区其它成人稿：白话、短句、分节「一 / 二 / 三」  
- 对话优先用 `「」`  
- 器官可直写，但避免连续纯动作段超过必要；插入内心与关系潜台词  
- 禁用原文广告句
