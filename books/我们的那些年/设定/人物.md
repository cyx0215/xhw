# 人物设定 · 《我们的那些年》

## 主角

### 牧宁越

| 项目 | 内容 |
|------|------|
| 姓名 | 牧宁越 |
| 年龄 | 现在线约 30+；闪回小学→高中 |
| 身份 | D 市广告公司老板（「牧总」） |
| 外貌关键词 | 爱美好靓、常年健身、风衣名牌、精致里藏毛躁 |
| 性格关键词 | 嘴硬、好面子、占有欲强、行动派、记仇也记恩 |
| 性向 / 性角色 | 男同性恋；偏 **攻**（重写中可明确主导，但初夜可生涩） |

#### 背景

- 出身：母亲苗老师（大学任教，已故）；父亲 mt 单位技术骨干，常年外派，后对顾有「安排」  
- 关键：小学班长「帮扶」顾裴江 → 两家往来 → 高考后顾离城 → 成年后爱而不得、撞见「开门男孩」决裂  
- 当前：事业有成，私生活看似游刃有余，实则卡在顾裴江这根刺上  

#### 动机与目标

- 表层：同学会应付场面；否认「我们开始过」  
- 深层：要顾裴江**主动要他**，而不是永远「听你的」却在关键时不听  
- 恐惧 / 软肋：被当成弟弟/被父亲安排的棋子；被选后的人  

#### 人物弧线

- 起点：犯贱式思念 + 冷暴力自保  
- 转折：第一次被顾裴江失控地碰触/进入后，发现「守礼」不是不爱  
- 终点：敢把「我要你」说出口，并接受顾的亏欠与边界

### 顾裴江

| 项目 | 内容 |
|------|------|
| 姓名 | 顾裴江 |
| 年龄 | 与牧宁越同龄或略长（牧称「哥」） |
| 身份 | 早年 M 市打工起步，现在线已有身价；曾东郊置业 |
| 外貌关键词 | 笑起来让人心跳；腹肌；淡定外壳 |
| 性格关键词 | 沉默、守礼、敏感、责任感重、爱用行动不爱解释 |
| 性向 / 性角色 | 男同性恋；偏 **受** 但体格不弱；床上克制→一旦放开很凶/很缠（重写可定） |

#### 背景

- 出身：乡下母亲+弟弟 → 进城子弟学校；口音被排挤  
- 关键：受牧家照顾；高考日顾父脑梗缺考；放弃复读；经牧父介绍去 M 市  
- 裂痕：牧回国撞见年轻男孩（旧情人/被照顾者，**待重写定性**）  

#### 动机与目标

- 表层：请庄晏艾撮合见面，「不想再僵持」  
- 深层：配得上牧宁越；补偿离散；在不被当成「父亲的棋」的前提下复合  
- 恐惧：拖累牧家；被牧当成施舍对象；自己的欲会「弄脏」竹马  

#### 人物弧线

- 起点：守礼到让牧遗憾「连妄念都不留」  
- 转折：被「哪会等到现在」刺中 → 签售会后先破戒  
- 终点：能说「我想要你」，也能说「当年我不是不选你」
