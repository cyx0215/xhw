# 大纲 · 《灵鹫之后》

## 作品信息

| 项目 | 内容 |
|------|------|
| 书名 | 灵鹫之后 |
| 类型 | 武侠续作（虚竹主线） |
| 预计篇幅 | 20 章，约 6–10 万字 |
| 核心卖点 | 好人如何掌权；夹缝中的情义与拒绝 |
| 一句话故事 | 婚后一年，虚竹被谣言、旧部、朝堂与中原清议同时推上台前，他须学会护谁、接什么权、拒什么忙 |

## 主题

- 主轴：情义与权柄
- 辅线：梦姑共治；兄弟影（乔峰余震、段誉轻触）
- 基调：苍凉里带暖
