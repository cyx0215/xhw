# 人物设定

## 主角：虚竹

| 项目 | 内容 |
|------|------|
| 身份 | 逍遥派掌门、灵鹫宫主、西夏驸马 |
| 武功 | 北冥、天山六阳、生死符、少林底子等 |
| 底色 | 仁厚、被动中带担当 |
| 弧线 | 不会拒绝 → 学会拒绝与边界 → 守势智慧立住三角平衡 |

## 女主：梦姑 / 李清露

西夏公主。有主见、傲气与柔情。宫廷直觉；与虚竹共治落点。
